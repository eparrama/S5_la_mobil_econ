# S5_la_mobil_econ
S5 Proyect LATAM Mobility &amp; Economy 
El objetivo es evaluar cómo la movilidad urbana se relaciona con la productividad económica en las principales ciudades latinoamericanas. Para ello utilizamos datos reales de TomTom Traffic Index y OECD Cities, que vamos a limpiar, combinar y analizar para identificar en qué ciudades conviene invertir en infraestructura de transporte.
